JobLookup Capture for Chrome and Edge

1. Extract the downloaded archive to a permanent local folder.
2. Open chrome://extensions or edge://extensions and enable Developer mode.
3. Choose Load unpacked and select that folder.
4. Open a job posting and use JobLookup Capture from the extensions menu.

JobLookup must be running. Review the captured posting before confirming import.
The workspace address is preconfigured by the app that supplied this download.
Change it in the popup if you later use a different local port.

The extension has activeTab, scripting and local storage permissions only.
It reads the selected text, visible main-page text, and JobPosting structured
data when clicked. It never reads cookies, password fields, or other tabs.
It does not log in, submit applications, or bypass website restrictions.
Captures are passed to your local app in a URL fragment, not a remote service.
